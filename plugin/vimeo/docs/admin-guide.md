# Video Time Vimeo Player — Administrator guide

The Vimeo player plays Vimeo links in Video Time activities. It is part of Video Time and is enabled
when it is installed.

## Enabling and disabling

*Site administration ▸ Plugins ▸ Activity modules ▸ Video Time ▸ Video Time Plugins ▸ Manage Video
Time extensions* lists the players and extensions. Use the eye icon in **Hide/Show** to enable or
disable the Vimeo player. While it is disabled, Video Time does not treat any link as a Vimeo link.

## Settings

*Site administration ▸ Plugins ▸ Activity modules ▸ Video Time ▸ Video Time Plugins ▸ Video Time
Vimeo Player*

### Default Settings

The default embed options of new Vimeo activities. Teachers change them per activity on the
activity's *Embed options* page. Changing a default does not change existing activities.

| Option | Default |
| --- | --- |
| Responsive | Yes |
| Height, Max height, Max width, Width | Empty |
| Autoplay | Yes |
| Byline | Yes |
| Color | `00adef` |
| Controls | Yes |
| Loop | No |
| Muted | No |
| Plays inline | Yes |
| Portrait | Yes |
| Speed | Yes |
| Title | Yes |
| Transparent | Yes |

The *Video Time Vimeo Player — Teacher guide* explains what each option does.

### Forced settings

The options selected in **Forced settings** take their default value in every Vimeo activity and
override the activity's own value. Teachers see the forced value on the *Embed options* page and
cannot change it. Nothing is forced by default.

### Advanced settings

The options selected in **Advanced settings** are shown only after **Show more...** on the *Embed
options* page. By default these are Byline, Height, Max height, Max width, Muted, Loop, Plays
inline, Portrait, Title, Transparent and Width.

## Video Time Pro

With Video Time Pro, the *Embed options* page also has **Do not track**, **Autopause**,
**Background** and **Picture-in-picture**. Their defaults are Pro settings; see the Pro
documentation.
