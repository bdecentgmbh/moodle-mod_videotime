# Video Time Block tab — Teacher guide

The Block tab adds a **Blocks** tab to a Video Time activity. You fill it with blocks, as on any
other Moodle page, and participants see the blocks next to the video.

## Switching it on

In the activity settings, under **Tabs**:

1. Check **Enable tabs**.
2. Check **Show tab** next to **Video Time Block tab**.
3. Optionally enter a **Custom tab name**. Without one, the tab is called **Blocks**.
4. Save.

The fields only appear when your administrator has enabled the tab for the site.

## Adding blocks

Open the activity and turn editing on. The tab has two block regions; new blocks are added to the
first one. Add, configure and move blocks as usual. On wide screens the two regions are shown side
by side when both contain blocks.

Edit the blocks on the activity page. When the activity is shown on the course page and editing is
on, the tab shows "These blocks should be edited on Video Time view page" and a **Go to view page**
button.

## What participants see

A tab with the blocks you added, next to the video.
