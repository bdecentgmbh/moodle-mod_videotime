# Video Time Block tab — Administrator guide

The Block tab gives Video Time activities a tab with two block regions. It is not enabled when it is
installed.

## Enabling the tab

*Site administration ▸ Plugins ▸ Activity modules ▸ Video Time ▸ Video Time tab plugins ▸ Manage
Video Time tab plugins*: use the eye icon in **Hide/Show**. The arrows in **Order** set the position
of the tab among the other tabs.

While the tab is disabled, its settings page is not listed in the menu; the **Settings** link on the
management page still opens it.

## Settings

*Site administration ▸ Plugins ▸ Activity modules ▸ Video Time ▸ Video Time tab plugins ▸ Video
Time Block tab*

**Default** (checked by default): whether **Show tab** is checked for the Block tab in new
activities.
